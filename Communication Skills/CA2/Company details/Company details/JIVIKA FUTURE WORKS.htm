Job Profile

Role: Mobile App Developer Intern

Job Profile:
** Contribute to App Development: Work on new features, UI components, and enhancements for Jivika's mobile apps using React Native.
** Bug Fixes & Optimizations: Identify bugs and performance issues and help fix them in coordination with the team.
** Collaborate with Backend Team: Integrate APIs and assist in end-to-end feature delivery.
** User-Centric Thinking: Translate UI/UX designs into clean, functional, and responsive interfaces.
** Participate in Code Reviews & Sprints: Be involved in sprint planning, testing, and review cycles.
** Learn & Build: Gain hands-on experience and industry best practices in mobile development.

Skills Set Required:
** Hands-on with React Native: Familiar with JavaScript/TypeScript, React Native components, navigation, and state management (e.g., Redux, Context API).
** Basic Understanding of APIs & Databases: Know how REST APIs work and how to integrate them into apps.
** Familiar with Tools: Comfortable using version control (Git), testing tools, and platforms like Expo, Firebase and MongoDB.
** Quick Learner: You’re eager to pick up new technologies and apply them in real-world scenarios.
** Problem-Solver: You can debug issues and think logically to create clean solutions.
